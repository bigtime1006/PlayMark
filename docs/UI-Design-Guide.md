# PlayMark UI 设计指南

## 项目概述

**应用名称**: 秒记 / Highlight Marker
**平台**: iOS (主管理端) + watchOS (记录端)
**核心价值**: 运动中一键标记"精彩瞬间"，赛后快速导出时间点与视频片段

## 设计原则

### 核心设计理念

- **运动友好**: 大按钮、高对比度、单手操作优化
- **即时反馈**: 触觉反馈、视觉确认、状态清晰
- **简洁高效**: 减少操作步骤，专注核心功能
- **一致性**: 跨平台设计语言统一

### 色彩系统
**设计更新：** 引入一套全新的“活力”色彩方案，以增强应用的动感和现代感。

```swift
// 活力色彩方案 (Lively Theme)

// 基础色
livelyBackground: #FFFFFF (浅色) / #121212 (深色) - 背景色
livelySurface: #F8F9FA (浅色) / #1E1E1E (深色) - 卡片/次级背景
livelyTextPrimary: #1C1C1E (浅色) / #FFFFFF (深色) - 主要文字
livelyTextSecondary: #6C757D (浅色) / #A9A9A9 (深色) - 次要/辅助文字

// 功能色
livelyPrimary: #FF7A00 - 活力橙，用于主要操作按钮（开始）
livelySuccess: #28A745 - 成功绿
livelyError: #DC3545 - 危险/删除/结束红

// 标签强调色 (Accent Colors for Tags)
livelyAccent1: #007BFF - 明亮蓝
livelyAccent2: #20C997 - 青绿色
livelyAccent3: #6F42C1 - 葡萄紫
livelyAccent4: #FFC107 - 警告黄
```

## iOS 端详细界面规范

### 1. 标记瞬间 (CaptureView) - 核心界面
**设计规格**:
- **页面背景**: pmBackground (系统背景色)
- **头部高度**: 56pt
- **按钮高度**: 主按钮48pt, 次要按钮44pt
- **边距**: 水平16pt, 垂直8pt
- **圆角半径**: 按钮12pt, 卡片12pt

**组件细节**:
- **开始/结束按钮**: pmPrimary背景色, pmBackground文字色, 胶囊形状
- **次要按钮**: pmSurface背景色, pmText文字色
- **禁用状态**: 透明度0.5, 保持原有样式
- **进度条**: 高度8pt, pmTrack背景, pmPrimary进度

**图标规范**:
- 使用SF Symbols系统图标
- 图标大小: 导航栏24x24pt, 按钮内嵌20x20pt
- 颜色: pmText主色

### 2. 历史记录页 (HistoryView)
**列表项设计**:
```
┌─────────────────────────────────────┐
│ 2025年8月23日                       │ ← 主标题 (pmText, 16pt)
│ 时长 12:34 · 标记 8                 │ ← 副标题 (pmMuted, 14pt)
└─────────────────────────────────────┘
```

**功能要求**:
- 下拉刷新支持
- 左滑删除操作 (红色删除按钮)
- 多选模式支持
- 搜索栏置顶

### 3. 会话详情页 (SessionDetailView)
**导出选项设计**:
```
┌─────────────────────────────────────┐
│ ○ CSV                               │ ← 选中状态: ● 实心圆
│ ○ 文本                              │
│ ○ JSON                              │
└─────────────────────────────────────┘
```

**标记点列表项**:
```
┌─────────────────────────────────────┐
│ 123.456 s                           │ ← 相对时间 (pmText, 16pt)
│ 2025-08-23T10:30:45Z                │ ← 绝对时间 (pmMuted, 12pt)
│                          进球       │ ← 标签 (右对齐, pmMuted)

```

### 4. 标签管理页 (ProfileListView)
**运动类型项**:
```
┌─────────────────────────────────────┐
│ 足球运动          ✓                 │ ← 选中状态显示对勾
│ 篮球运动                            │
└─────────────────────────────────────┘
```

**标签项设计**:
```
┌─────────────────────────────────────┐
│ ● 进球                              │ ← 颜色圆点 + 标签名称
│ ● 助攻                              │
└─────────────────────────────────────┘
```

### 5. 视频导入页 (VideoImportView)
**分段控件设计**:
- 使用SwiftUI Section分隔不同功能区块
- 每个Section有明确标题
- 输入框有占位符提示
- 按钮状态明确 (启用/禁用)

**时间输入格式**:
- 支持 mm:ss.s 格式 (如: 1:23.4)
- 支持 ss.s 格式 (如: 83.4)
- 实时格式验证

## 详细用户场景与交互流程

### 场景1: 完整运动记录流程

**用户目标**: 在运动过程中快速标记关键事件，赛后查看和分析

**手表端交互**:
1. **开始记录**: 用户点击"开始"按钮
   - 视觉: 界面切换为进行中状态，显示计时器和标签网格
   - 触觉: 播放开始反馈 (WKInterfaceDevice.current().play(.start))
   - 状态: 显示当前时长，展示4个标签按钮

2. **标记事件**: 发生精彩瞬间时
   - 用户点击对应标签按钮 (如"进球")
   - 视觉: 按钮按下效果
   - 触觉: 成功反馈 (.success)
   - 状态: 保持界面响应

3. **结束记录**: 运动结束

   - 点击"结束"按钮 (红色强调)
   - 触觉: 停止反馈 (.stop)
   - 自动: 生成会话数据，尝试发送到iPhone

**手机端响应**:
1. **接收数据**: 自动后台接收Watch会话
2. **通知提示**: 显示"新会话已保存"通知
3. **界面更新**: 历史列表自动刷新显示新会话
4. **数据处理**: 会话数据持久化存储

### 场景2: 视频剪辑导出流程

**详细步骤**:
1.  **入口与选择**:
    -   从主导航进入“视频编辑”页。
    -   页面默认加载最近的会话。
    -   用户通过“从相册选择”或“从文件导入”来指定视频源。

2.  **对齐与参数设置**:
    -   选择对齐模式（会话开始/第一标记）。
    -   输入视频中的对齐时间点。
    -   使用 `Stepper` 设置全局的 `preRoll` 和 `postRoll` 时长。

3.  **字幕编辑 (可选)**:
    -   用户可以为视频添加一个可选的片头标题和时长。
    -   可以为列表中的每一个“精彩瞬间”单独编辑字幕文本。

4.  **生成与预览**:
    -   点击“生成片段预览”，App根据以上设置计算出所有视频片段。
    -   片段列表会显示在下方。
    -   用户可以点击任意片段，在弹出的预览浮层中观看效果。
    -   在预览浮层中，可以临时调整 `preRoll`/`postRoll` 并实时观看效果，并选择是否将该调整应用到所有片段。

5.  **导出选项**:
    -   用户通过 `Toggle` 开关决定是否将字幕“烧录”到视频中，以及是否额外导出一份 `.srt` 字幕文件。

7. **最终导出**:
   - 进度显示: 导出进度条或百分比
   - 完成处理: 调用系统分享面板

### 场景3: 标签管理系统流程

**用户目标**: 自定义运动类型和标记标签，同步到手表

**管理流程**:
1. **入口访问**: 点击首页头部Profile名称
2. **Profile切换**:
   - 浏览现有运动类型列表
   - 点击切换当前类型
   - 视觉反馈: 选中状态指示

3. **标签编辑**:
   - 查看当前类型的所有标签
   - 每个标签显示颜色标识和名称
   - 进入详细编辑界面修改

4. **同步操作**:
   - 手动触发同步到手表
   - 同步状态反馈 (成功/失败)
   - 确保手表端及时更新

5. **多设备一致性**:
   - iPhone修改后需要手动同步
   - Watch端缓存最后一次配置
   - 离线时使用缓存配置

### 场景4: 数据导出与分析

**用户目标**: 导出标记数据用于进一步分析

**导出选项**:
1. **CSV格式**:
   - 表头: timestamp_seconds,actual_time_iso,tag
   - 适合Excel、Numbers等表格软件

2. **文本格式**:
   - 友好阅读格式
   - 包含会话元信息
   - 时间点列表清晰

3. **JSON格式**:
   - 完整数据结构
   - 适合程序处理
   - 包含所有元数据

**分享流程**:
1. 选择格式后点击"分享"
2. 调用系统分享面板
3. 支持AirDrop、邮件、消息等
4. 自动生成临时文件并清理

### 错误处理场景

**网络同步失败**:
- 手表端: 显示同步失败提示，建议稍后重试。
- 手机端: 显示连接状态，提供手动重试。

**视频处理错误**:
- 格式不支持: 明确错误提示，建议转换格式。
- 时间计算错误: 提供重新对齐选项。
- 导出失败: 详细错误原因，重试机制。

## 设计建议与最佳实践

### 视觉设计方向建议

**1. 运动科技风格**
- **渐变效果**: 适当使用 subtle 渐变提升现代感,  但避免过度使用

**2. 专业工具感**
- **简洁界面**: 减少视觉噪音，专注功能
- **一致性**: 保持跨平台设计语言统一
- **精准感**: 时间显示、数据格式要精确专业

**3. 情感化设计**
- **成功反馈**: 标记成功时的愉悦反馈
- **成就感**: 展示统计数据，增强用户成就感
- **个性化**: 允许一定程度的自定义

### 具体设计建议

**色彩系统优化**:
```swift
// 建议的色彩方案（可调整）
primary: #FF7A00 (活力橙)
secondary: #6C757D (中性灰)
success: #28A745 (绿色)
warning: #FFC107 (黄色)
error: #DC3545 (红色)

// 深色模式适配
// 确保所有颜色在深色模式下都有良好对比度
```

**字体选择**:
- **中文字体**: PingFang SC (苹方)
- **英文数字**: SF Pro Display/SF Pro Text
- **字重搭配**:
  - 标题: Semibold (600) 或 Bold (700)
  - 正文: Regular (400) 或 Medium (500)
  - 辅助文字: Regular (400)

**图标设计规范**:
- **系统图标**: 优先使用SF Symbols，保持一致性
  - 导航栏: 24×24pt
  - 按钮内: 20x20pt
  - 标签按钮内嵌24x24pt
  - 列表项: 18×18pt

**动效设计建议**:
1. **微交互**:
   - 按钮点击: 轻微缩放+透明度变化
   - 状态切换: 平滑过渡动画
   - 页面转换: 标准导航动画

2. **加载状态**:
   - 使用系统活动指示器, 可自定义
   - 自定义进度条动画
   - 骨架屏加载效果

3. **成功反馈**:
   - 勾选动画
   - 完成震动反馈
   - 状态变化提示

### 可访问性设计


**文字可读性**:
- 动态类型支持: 支持系统字体大小调整
- 行高: 1.2倍字高，确保阅读舒适

**颜色对比度**:
- 文本与背景: 至少4.5:1 对比度
- 大号文字: 至少3:1 对比度
- 非文本元素: 至少3:1 对比度

**交互可访问**:
- 触控区域: 最小44×44pt
- 焦点指示: 清晰的可视化焦点状态
- 语音Over: 完整的语音描述支持
