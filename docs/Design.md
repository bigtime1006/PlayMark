## 设计文档（产品/交互/信息架构）

- **产品名称**: 秒记 / Highlight Marker
- **目标人群**: 体育运动参与者与教练；需要快速打点、赛后复盘与剪辑

### 核心价值
- 一键标记运动中的“精彩瞬间”，赛后快速导出时间点与视频片段

### 主要场景
- 比赛/训练中：Apple Watch 单手操作，低时延打点（< 200ms）
- 赛后：iPhone 查看活动、编辑时间点、导出清单/视频片段

### 功能清单（当前）
- iPhone：开始/结束/标记；历史记录与详情编辑；回收站；视频导入对齐与导出（合并 MP4、SRT、可选烧录字幕）
- Watch：开始/结束；四个快捷标签；最近活动浏览、编辑与撤销
- 同步：Watch → iPhone 会话与打点传输；iPhone → Watch 标签配置（含颜色、Profile 名称）

### 信息架构（iPhone）
- 首页：开始/结束、标记、当前 Profile 名称与同步、历史入口、视频入口
- 历史：搜索/排序，选择与批量删除，回收站
- 详情：标题/备注，时间点列表（筛选/排序/批量删除），时间点编辑页
- 标签管理：Profile 列表、编辑标签（名称+颜色）、手动同步到手表
- 视频：选择会话与视频、对齐、片段参数、预览、导出

### 信息架构（watchOS）
- 主页：Profile 名称；四快捷标签网格；结束按钮
- 最近活动：列表、详情页（时间点编辑/删除）、撤销

### 交互与视觉
- 颜色：`pmBackground/pmSurface/pmText/pmMuted/pmTrack/pmPrimary`
- 按钮：主操作为胶囊+主色，次要操作为描边或浅底
- 文案：全中文；标签颜色与名称在 Watch 上直观区分

### 数据模型（V2 扩展）
- Highlight: id, timestamp, createdAt, tag?, updatedAt?, deletedAt?
- RecordSession: id, startedAt, endedAt?, highlights[], note?, title?, updatedAt?, deletedAt?

### 视频流水线（摘要）
- 视频信息与校验：选中视频后显示“开始/时长/结束”；与会话绝对时间范围比对并提示覆盖状态
- 建议对齐锚点：基于“视频开始时间 + 会话开始/首记绝对时间”自动计算建议偏移秒数，支持一键填入
- 对齐模式：会话开始→视频时间；第一个标记→视频时间
- 片段：每个标记生成 [preRoll, postRoll]；重叠自动合并
- 导出：合并 MP4（可选烧录字幕）、SRT 字幕；分享面板

### 非功能性要求
- 打点时延 < 200ms；电量友好；本地数据隐私
